# H1 Implementation Scope

This batch is intentionally limited to what can be done with the repository's current infrastructure.

Allowed: existing Next.js server routes, Firebase/Firebase Admin, existing wallet authentication/signature helpers, existing RPC/blockchain integrations, existing UI/components/dependencies.

Not allowed: adding a new external API, new paid infrastructure, new cloud job, new transaction provider, or redesigning the existing transaction execution rails.

If a requested improvement requires a new external service/API, it is deferred rather than added.
